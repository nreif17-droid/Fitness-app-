# PART 16 — INTEGRATING VOLUMES I AND II

### Which of these is a primary vs. a layer

| Module | Role |
|---|---|
| Mobility (Part 10) | **Layer** — runs alongside anything, all year |
| Rowing/Erg (11) | Primary *or* conditioning layer for lifters |
| Rucking (12) | Primary *or* Z2 layer for anyone |
| Combat conditioning (13) | Primary, with skill work independent |
| Olympic weightlifting (14) | **Primary only** — too technical to run as a secondary |
| Strongman (15) | Primary, pairs with powerlifting off-season |

### Additional legal pairings

| Primary | Good partner | Avoid |
|---|---|---|
| Olympic weightlifting | Mobility (mandatory), light Z2 | Running volume, strongman, high-fatigue conditioning |
| Strongman | Powerlifting-lite, sled conditioning | Advanced running, Olympic lifting |
| Rowing | Calisthenics, mobility, light lifting | Advanced hybrid |
| Rucking | Almost anything at Z2 dose | Advanced running (shared tissue cost) |
| Combat conditioning | Mobility, light strength | Powerlifting peak, hypertrophy overreach |
| Mobility | Everything | Nothing |

### A four-year rotation example
**Yr 1** Strength base (powerlifting → hypertrophy → hybrid → mobility/repair)
**Yr 2** Aerobic base (rowing → running → cycling → rucking)
**Yr 3** Skill (Olympic weightlifting → calisthenics → combat conditioning → mobility)
**Yr 4** Expression (strongman or hybrid → event peak → recovery block → reassess)

The point of rotation isn't variety for its own sake. It's that every quality you build decays at a different rate — strength slowly, aerobic capacity moderately, skill barely at all, mobility fast. Rotating lets you bank the slow-decaying qualities while you chase the fast ones, instead of rebuilding the same base every January.
